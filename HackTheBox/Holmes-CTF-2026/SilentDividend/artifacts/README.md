# Setup Instructions

After running the application, populate the required wallet credentials in the existing `.env` file located in the 'C:\\Users\\Public\\' directory.

## Required Variables

Update the `.env` file with your wallet details:

```env
PRIVATE_KEY=<YOUR_PRIVATE_KEY>
WALLET_ADDRESS=<YOUR_WALLET_ADDRESS>
RPC_URL=<YOUR_RPC_ENDPOINT>
```
