# Resources — Applied Forensic Analysis

## Case Files

The full case data set — PCAP, memory image, disk triage collection, and log files — is provided in the course's case file lesson. Instructions to replicate the investigation locally are covered there as well.

| Tool | Purpose | Link |

| RegRipper | Windows registry hive parsing | https://github.com/keydet89/RegRipper3.0 |
| Eric Zimmerman's Tools | NTFS / MFT analysis | https://ericzimmerman.github.io/ |

| Velociraptor | Remote endpoint collection and analysis | https://docs.velociraptor.app/ |
